Adding a New Language

The project uses .po files to manage multilingual text. All language files are stored in:

resources/languages

To add a new language:

  1. Navigate to the resources/languages directory and copy an existing .mo file as a template.
  2. Rename the file according to the target language (for example, en_US.mo or ja_JP.mo).
  3. Open the file with a text editor or a PO editor (such as Poedit) and translate the msgstr entries.
  4. Save the file.
  5. Add the corresponding local language mapping in libs/graphics/settings.py.
  6. Create libs/graphics/wen/document-{language}.html, where {language} matches the .mo file name. The content inside need to be translated.
  7. Create resources/prompts/prompts-{language}.json, where {language} matches the .mo file name.，The prompt inside need to be translated.
Note: msgid is the original key and must not be modified. Only translate the corresponding msgstr values.
